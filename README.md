# AgroMarket - Módulo Catálogo

Módulo de catálogo de productos para la plataforma AgroMarket, una
aplicación web de comercialización de productos agrícolas. Este módulo
permite visualizar el listado de productos disponibles, filtrarlos por
categoría (frutas, hortalizas, granos) y acceder al detalle de cada uno.
